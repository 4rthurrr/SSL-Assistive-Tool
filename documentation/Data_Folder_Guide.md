# 📂 Backend Data Folder Guide

This directory (`backend/data/`) contains the "Fuel" for your AI and NLP engines.

## 1. The Core Datasets (Heavy Weights) 🏋️‍♂️
*   **`grammar_dataset.csv`** (585 MB):
    *   **Purpose:** The main dataset for training the **Grammar Model** (Seq2Seq/Transformer).
    *   **Content:** Millions of sentence pairs (Sinhala -> SSL Gloss).
*   **`grammar_dataset_augmented.csv`** (3 GB):
    *   **Purpose:** An expanded version of the dataset with even more variations.
    *   **Note:** This is likely used for "Deep Training" sessions.

## 2. The AI Training Data 🧠
*   **`vocabulary_expanded.txt`** (200 KB):
    *   **Purpose:** The clean, grammatically strict list of Sinhala words used to train **Word2Vec**.
    *   **Source:** Generated by `generate_morphology.py`.
    *   **Content:** "Potha Pothak", "Balla Ballek" (Root mapping).
*   **`training_data.json`** (80 MB):
    *   **Purpose:** The processed, "Ready-to-Eat" data for `train_pipeline.py`.
    *   **Content:** Tokenized sentences and label IDs used during the actual training process.

## 3. Legacy / Helper Files 📜
*   **`bilingual_pairs.csv`** & **`pairs.csv`**:
    *   **Purpose:** Likely older or smaller datasets used for early testing or specific simple mappings.
*   **`integration_note.txt`**:
    *   **Purpose:** Notes on how these files are connected (Documentation).

## ⚡ Summary
| File | Engine | Role |
| :--- | :--- | :--- |
| `vocabulary_expanded.txt` | **Word2Vec** | Teaches "Morphology" (Word variations). |
| `grammar_dataset.csv` | **Transformer** | Teaches "Sentence Structure" (Grammar). |
| `training_data.json` | **Training Script** | Intermediate cache file for speed. |
